## 🌌 Overview

**PUNKFOLIO** is a retro-futuristic, cyber-themed portfolio web application built for **Tathagat Aryan**. Designed with cutting-edge visual aesthetics, holographic glassmorphism, real-time API integrations, synthesized spatial sound effects, and an interactive 60 FPS HTML5 canvas environment.

---

## ⚡ Features

### 🏙️ 1. Interactive 60 FPS Cyber Canvas Engine
- **Dynamic Weather System**: Particle rain simulator reacting with ambient physics.
- **Flying Hovercraft Traffic**: Ambient futuristic vehicles flying across atmospheric neon skies with dynamic headlight ray projection and exhaust particle trails.

### 🔊 2. Pure Web Audio API Synthesizer
- Zero external MP3/WAV assets — 100% generated procedural cyber sound effects (chimes, clicks, hover tones, and UI interactions) using native oscillators and gain nodes.
- Global HUD audio mute / enable controls.

### 📊 3. Live LeetCode API Telemetry
- Real-time live profile telemetry synchronizing problem statistics, solved counts (Easy / Medium / Hard breakdown), and global ranking dynamically via live API.

### 🧠 4. Circuit Mind-Map Contact Matrix
- Custom SVG circuit-trace architecture connecting all digital presence nodes (**GitHub, LinkedIn, Email, LeetCode, Instagram, Resume**) with illuminated neon routes, glowing junctions, and direct Gmail web compose redirection.

### 💎 5. Frosted Glassmorphism HUD
- Multi-layer frosted glass panels (`backdrop-blur-md`), specular reflection lightbars, and neon glow accents (`#00f0ff` Cyan, `#ff007f` Magenta, `#f59e0b` Amber).
- Real-time live digital clock and date telemetry.

## 🚀 Getting Started

### Prerequisites
- Node.js (v18.0.0 or higher recommended)
- npm / yarn / pnpm

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Aryan689t/punkfolio.git
   cd punkfolio
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the local development server:**
   ```bash
   npm run dev
   ```

4. **Build for production:**
   ```bash
   npm run build
   ```

5. **Preview production bundle:**
   ```bash
   npm run preview
   ```
